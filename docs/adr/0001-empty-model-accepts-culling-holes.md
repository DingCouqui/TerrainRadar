# 用空模型实现完全隐藏，并接受实心方块的剔除洞

## Status

accepted

## 背景与决定

「完全隐藏」的视觉要求（无几何、无边框线）用空模型实现：每个隐藏方块的 blockstate 指向一个只有 `textures.particle`、没有 `elements` 的模型。代价是**隐藏实心方块必然留下洞**：面剔除依据方块状态的遮挡形状而不是模型几何，资源包没有任何手段关闭它（`cullface`/`ambientocclusion` 都改不了邻居的剔除判定）。我们接受这些洞，而不是改用线框、半透明或引入 Mod。

## Considered Options

- **0.5px 线框（参考实现的做法）**：能定位隐形方块，但违背「完全隐藏、不保留边框线」。
- **半透明贴图**：仍然保留视觉残留，且同样无法消除洞，只是把洞藏在半透明表面之后。
- **Mod（如 Fabric mixin 关掉 `noOcclusion` 缺失的问题 / 改光照）**：能真正解决洞与森林光照，但违背「纯 Java 资源包、零依赖」的交付形态。

## Consequences

- 原木/木/菌柄/菌核/蘑菇方块/疣块/菌光体/南瓜/西瓜/雪层第 8 层会在与其它实心方块接触处出现可透视缺口，位置可预期（树干根部等），已写进 `docs/TESTING.md` 与 `docs/BLOCK-LIST.md`。
- 隐藏实心方块同时带来局部透视副作用；公开发布时需要在说明里写清。
- 光照不变：森林下的地形仍然偏暗（天光遮挡由方块自身决定），不因此改用一个需要 OptiFine 的 lightmap。
