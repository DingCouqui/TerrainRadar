# 用空模型实现完全隐藏，并接受实心方块的剔除洞

## Status

accepted

## 背景与决定

「完全隐藏」的视觉要求（无几何、无边框线）用空模型实现：每个隐藏方块的 blockstate 指向一个只有 `textures.particle`、没有 `elements` 的模型。代价是**隐藏实心方块会留下洞**：面剔除依据「邻居方块状态的遮挡形状」，资源包无法在隐藏方块一侧关闭它。我们接受这个机制，并在此之上用**去剔除覆盖**缓解最常见的情况（见 `docs/adr/0003-*`）：给要显示的那一侧方块去掉 `cullface`，它的面就不再被邻居剔除——这与参考包让被包裹矿石保持可见是同一个原理。

## Considered Options

- **0.5px 线框（参考实现的做法）**：能定位隐形方块，但违背「完全隐藏、不保留边框线」。
- **半透明贴图**：仍然保留视觉残留，且同样无法消除洞，只是把洞藏在半透明表面之后。
- **Mod（如 Fabric mixin 关掉 `noOcclusion` 缺失的问题 / 改光照）**：能真正解决洞与森林光照，但违背「纯 Java 资源包、零依赖」的交付形态。

## Consequences

- 32 个实心隐藏方块会在与其它实心方块接触处留下可透视缺口；位置可预期，已写进 `docs/TESTING.md` 与 `docs/BLOCK-LIST.md`。
- v0.2.0 起对 11 个承载积雪的地表方块去掉 up 面 `cullface`，修复雪地地表与树干根部的空洞；未覆盖的方块（石头/泥土/深板岩等）、玩家建筑、以及非 "上表面" 的接触面仍可能有洞。
- 隐藏实心方块同时带来局部透视副作用；公开发布时需要在说明里写清。
- 光照不变：森林下的地形仍然偏暗（天光遮挡由方块自身决定），不因此改用一个需要 OptiFine 的 lightmap。
