# 对承载积雪的地表方块去掉 up 面 cullface（去剔除覆盖）

## Status

accepted

## 背景与决定

雪层会剔除它下方方块的上表面（雪层的「面遮挡形状」是完整方块），隐藏雪层后雪地会出现大片透视空洞；而保留雪层又会让树叶被隐藏后的树上积雪悬空。唯一的资源包侧解法在**要显示的那一侧**：方块的面是否被剔除，由「该面在模型里是否带 `cullface`」决定——不带 `cullface` 的面永远渲染。这正是参考包让被隐形石头包裹的矿石保持可见的原理。

因此对 19 个常承载积雪的地表方块（`grass_block`、`podzol`、`mycelium`、`coarse_dirt`、`pale_moss_block`、`snow_block`、`blue_ice`、`sand`、`red_sand`、`gravel`、`farmland`，以及山体上的 `stone`、`dirt`、`deepslate`、`tuff`、`calcite`、`andesite`、`granite`、`diorite`）做去剔除覆盖：复制原版模型链，去掉 `up` 面的 `cullface`，并让这些方块的 blockstate 指向副本。只去掉 up 面（而不是全部面）是为了把额外渲染控制到「每个方块多 1 个面」；其中石头/泥土/深板岩等地下体积大的方块会带来可感知的开销，需要实测 FPS。

另提供 26.1 专用的**全量去剔除实验包**（`tools/experiment_nocull_all.py` → `dist/TerrainRadar-<version>-nocull-all-26.1.zip`）：所有方块的所有面都不剔除，用来验证「洞彻底消失」的视觉效果与实际 FPS 代价；它的模型几何来自 26.1，只在 26.1 测试。

## Considered Options

- **不隐藏雪层**：零开销，但树上积雪悬空，且用户明确不接受。
- **全量去剔除（所有方块所有面）**：洞彻底消失，但每个方块的所有面都渲染，地下实心区域的几何量成倍上升，FPS 代价明显；作为实验包提供，等实测结果再决定是否转正。
- **只覆盖自然地形方块的全部面**：自然地形上的洞（含侧面）都能修，但 `stone`/`dirt`/`deepslate` 体积巨大，全去掉 cullface 的开销不可接受；只修 up 面是折中。
- **Mod**：能彻底解决，但违背「纯资源包、零依赖」。

## Consequences

- 雪地地表、树干根部的空洞消失；树上积雪随雪层一起隐形，不再悬空。
- 玩家建筑上的积雪、原木贴着未覆盖地形的侧面、以及下界岩与疣块/菌光体的接触面仍可能出现洞；需要时可以往 `data/nocull.json` 加方块（代价是这些方块多渲染一个面），或改用全量去剔除实验包。
- 去剔除覆盖只改 blockstate 指向的模型副本，**不改 `models/block/<id>.json`**，所以物品栏图标/手持不受影响；副本复制自 26.1 原版模型，所选方块都是 1.20.2 以来几何稳定的方块。
- 生成物包含改写过的原版模型结构（去掉了 cullface）；本地自用无碍，若将来公开发布需单独评估合规性。
