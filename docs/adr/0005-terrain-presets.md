# 预设采用「植被 / 表层 / 深层」三段严格累加、数据写死为方块 ID

## 背景

旧的三个预设（默认 / 仅树叶 / 仅植物）只覆盖植被，且语义随资源包时代清单漂移；
新的使用场景需要「植被 → 表层 → 深层」逐层扩大隐藏范围，作为可预期的整份清单切换。

## 决策

- 三个预设严格累加：植被 ⊂ 表层 ⊂ 深层，点预设**整体替换**当前勾选。
- 内容写死为方块 ID（不运行时解析 tag）：
  - **植被** = 默认清单（129）+ 8 种玩家作物 = 137
  - **表层** = 植被 + 泥土/草方块/沙/沙砾/苔藓/雪/黏土/耕地/土径 = 156
  - **深层** = 表层 + 自然岩石（石头族、下界岩/玄武岩/黑石、砂岩/红砂岩）= 167
- 深层**不含**加工变体（圆石、石砖、磨制/切制/平滑等）、矿石、基岩；不含下界软表层（灵魂沙/灵魂土）。
- 旧预设名不再接受；旧配置中的 `preset` 加载时归一化为「自定义」并写回，隐藏清单本身不动。
- 点预设后点「应用」记录预设名；之后手动勾选/全选/反选把状态改为「自定义」。

## 考虑过的方案（已否决）

- **运行时用 tag 解析**（`#crops`、`#dirt`、`#sand`、`#base_stone_overworld` 等）：能自动包含模组/新版本方块，但预设边界随数据包变化、不易测试与文档化，且部分家族没有 tag。
- **预设合并进当前勾选**：多次点预设会不断膨胀，状态不可预期。
- **深层包含加工变体/矿石**：会把「深层预设」变成近似 Xray 的完整地下隐藏，超出“岩石层”语义。
- **旧名映射到新预设**：旧「仅植物」与新「深层」语义偏差大，硬映射会误导。

## 后果

- 模组方块不会自动进入预设，需要用户手动勾选。
- 默认清单更新会同时影响三份预设的基础部分；新增的作物/表层/深层方块需要在 `Presets.java` 手动维护。
- 由于深层隐藏大面积石头，选择该预设后地下会大面积透空，这是预期行为。
